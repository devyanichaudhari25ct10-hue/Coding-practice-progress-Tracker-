# Coding-practice-progress-Tracker-
💻 Coding Practice Progress Tracker

📌 About the Project

The Coding Practice Progress Tracker is a student-friendly application developed to manage and track daily coding practice activities.

This project helps students maintain records of coding problems, programming languages, difficulty levels, practice dates, and completion status. It is designed to encourage regular coding practice and improve programming skills.

The application uses Python for programming, Tkinter for the graphical user interface, and MySQL for database management.

🎯 Objectives

- To maintain a record of daily coding practice.
- To track completed coding problems.
- To organize problems according to difficulty level.
- To improve consistency in coding practice.
- To monitor learning progress.
- To develop programming and database management skills.

✨ Features

- Add new coding practice records.
- View saved coding records.
- Update existing records.
- Delete unwanted records.
- Store coding problem names.
- Select programming languages.
- Categorize problems as Easy, Medium, or Hard.
- Record practice dates.
- Track problem completion status.
- Provide a simple and user-friendly interface.

🛠️ Technologies Used

- Programming Language: Python
- Frontend: Tkinter
- Backend: Python
- Database: MySQL
- Development Environment: Python IDE / Pydroid 3

📂 Project Modules

1. Add Coding Record

Allows users to enter coding problem details, programming language, difficulty level, and practice date.

2. View Coding Records

Displays saved coding practice records.

3. Update Records

Allows users to modify existing coding practice details.

4. Delete Records

Allows users to remove unwanted coding records.

5. Progress Tracking

Helps users monitor their coding practice activities and completion status.

⚙️ Requirements

- Python 3.x
- Tkinter
- MySQL Server
- MySQL Connector for Python

🚀 How to Run the Project

1. Install Python on your computer.
2. Install and configure MySQL Server.
3. Create a database for the project.
4. Create the required database tables.
5. Install the MySQL connector package.
6. Configure the database connection in the Python code.
7. Run the main Python file.
8. Start recording and managing coding practice activities.
